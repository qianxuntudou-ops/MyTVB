## 1. HGTV 1.3.6（jadx 反编译，TV 端第三方客户端）

> 重要前提：该 APK 的 `jadx/resources/` 为空（资源反编译无产出），且源码中无任何 `R.layout` / Fragment / leanback 引用——**整个 App 的 UI 是纯 Java/Kotlin 代码逐 View 构建**，无 XML 布局。界面形态全部从建树代码反推。

### 1.1 整体架构与页面划分 `[一手]`

- 单 Activity（`com.hgtv.star.tv.MainActivity`，2911 行）+ 页面状态机：`h2` 字段取值 `"catalog" / "recommend" / "detail" / "player"`；catalog 内部又用 `a3` 编号：0=首页、1=搜索、2=分类、3=榜单、4=设置、5=我的。
  - 证据：`sources/com/hgtv/star/tv/MainActivity.java:1016-1046`（back 键按状态分发）、`sources/p011d1/AbstractC0385f.java:222-262`（页面→无障碍标题映射：首页/搜索/分类/榜单/设置/我的/推荐/详情/播放/记录）。
- 左侧（或边栏）导航按钮组：**推荐 + 搜索/分类/榜单/设置/我的**，每项带选中圆点指示（GradientDrawable 圆形，主题色）。
  - 证据：`sources/p011d1/L0.java:5458-5516`（`new C0400k(mainActivity, 2131034231, "推荐", …)` + `Q1.c.h("search",…"搜索")…h("profile",…"我的")` 列表 + 选中指示点）、`sources/p011d1/AbstractC0410n0.java:25`（`recommend/search/category/rank/profile` 五个导航项定义）。
- 导航项可被用户隐藏/排序（`q().L()` 为隐藏集合，渲染时跳过）。
- 「我的」页内子页签：**历史 / 收藏 / 点赞 / 预约**（`AbstractC0410n0.java:22`）。
- 设置分四组：**播放交互 / 外观导航 / 内容推荐 / 系高级**（`AbstractC0410n0.java:52`）。

### 1.2 首页信息架构 `[一手]`

首页 = 纵向 `ScrollView` 里的**横向卡片货架（Shelf）列表**，每条货架最多展示 10 张卡，行尾可带「查看全部 ›」入口卡：

- Shelf 模型：`Shelf(key, title, entries, more)`（`sources/p014e1/n.java:27`）。
- 货架构成（`sources/p011d1/L0.java:1410-1475`）：
  1. `history`（观看记录，卡片带「第 X 集 · 进度」角标与进度条）
  2. `favorites`（收藏，条目副标题「账号 · 收藏于 yyyy-MM-dd」）
  3. `later`（稍后观看，副标题「稍后观看 · 长按管理」）
  4. `rank-*` 榜单货架 ×4：**推荐榜(new) / 热播漫剧(comic) / 热播AI(ai) / 热播真人(real)**（`sources/F0/EnumC0211v2.java:15-20`），每条取前 10，≥10 条时挂「查看全部」回调进榜单页
  5. 分类货架（`W0.f1793a`）与 `related`/`author`（相关推荐/全部作品，`A/b.java:6442`）
- 首页底部「展示更多 ↓ / 加载失败 · 重试」按钮与「已显示 X 部」分页状态（`sources/p014e1/B.java:114-119, 951, 1771`）。
- **另有一个独立的「推荐」页**（`h2="recommend"`）：全屏自动连播推荐流，播完自动切下一部（`sources/p011d1/C0420q1.java:33-53`，`"暂时没有可播放的推荐\n按确定键重试，按返回键回主页面"`、`"这批推荐刷完了，稍后再来"`），遥控器帮助文案：`"确定 追剧 · 上下 换剧 · 左右 快进退 · 菜单 播放设置 · 返回 主页面"`（`L0.java:7225`）。
- 每行卡片数量可设置：**4~8 张，默认 6（紧凑）**（`sources/p011d1/C0407m0.java:229-233`「4 张 · 大卡片 / … / 6 张 · 紧凑（默认）/ … / 8 张 · 最紧凑」）。

### 1.3 卡片形态 `[一手]`

卡片基类 `p008c1.g`（`sources/p008c1/g.java`）+ TV 卡 `p011d1/R1.java`：

- **竖版海报卡**：图高 = 卡宽 ÷ 0.75，即 **宽:高 = 3:4 竖版**；图片 `CENTER_CROP`。证据：`sources/p014e1/p.java:1719-1726`（`return (int) (iG / 0.75f);`）、`g.java:186`（`imageView.setScaleType(ImageView.ScaleType.CENTER_CROP)`）。
- 结构：海报图 → 标题行（18sp 加粗，单行）→ 状态行（tagline 左 + 状态右，14sp）。
- **四个角标位**（圆角渐变底、白字加粗，12sp）：左上 `corner`（榜单名次/状态，支持双色横渐变底）、右上 `season`、左下 `heat`、右下 `badge`（集数「共 X 集」）。证据：`g.java:139-172`（四个 gravity：TOP|START / TOP|END / BOTTOM|START / BOTTOM|END）、`g.java:536-545`（`setEpisodeBadge` → "共 X 集"）。
- **榜单卡显示「第 X 名」**，且前三名走特殊样式（`sources/p014e1/B.java:1416, 1471, 1455-1458`：`"第 X 名"`；`num.intValue() > 3 ? false : true` 生成前三名专属标志位）。
- 其他状态文案：**「即将上线」「整剧已看完」「第 X 集 · 进度时间」「预告」「账号 · …」**（`B.java:1379-1428`）。
- 海报底部可叠加**观看进度条**（track+fill 双色，`g.java:127-133`）。
- 焦点态：**1.05 倍缩放（200ms DecelerateInterpolator）+ 抬升发光边框（1.35f）+ 标题跑马灯**。证据：`sources/p011d1/l2.java:38-56`（focus scale 动画）、`sources/p011d1/R1.java:88-110`（`f(boolean)`：`setEllipsize(MARQUEE)` + `l2.a(this, z2, 0.0f, 12)`）。
- 卡片状态文本超长截 8 字加 `…`，预告片显示「预告」（`p014e1/p.java:425-441`）。

### 1.4 榜单页形态 `[一手]`

- 榜单是 catalog 的 `a3=3` 模式：**分页网格**（非行式列表），复用 R1 海报卡 + 「第 X 名」角标，页间翻页（`b3` 页码、`f3` 选中剧 id：`A/b.java:2598-2608` 附近状态流转；渲染在 `p014e1/B.java:1330+` 网格函数）。
- 榜单数据按 `EnumC0211v2` 四榜（推荐/热播漫剧/热播AI/热播真人）组织；支持记录每部的名次映射 `C0215w2`（`L0.java:1451-1461`）。
- 失败降级：「刷新失败 · 仍显示上次榜单」（`L0.java:6666-6667`）。

### 1.5 详情页形态 `[一手]`

- 头部：**约 3:4 竖版大海报（高 240dp）** + 右侧信息列：标题 **34sp 加粗（最多 2 行）**；「★」评分图标用主题强调色；集数「X 集」（未上线显示「即将上线」）；标签行；简介（14sp 次要色，单行，可展开）；提示行「选择剧集开始观看」/「尚未上线，预约后开播时提醒你」。
  - 证据：`sources/A/b.java:2462-2510`（poster `Z0((iX*2)+(240*7/10), 240)`、`N2(…, 34.0f, …)` 标题、"★"、"X 集"、简介 f1775g 14sp、提示语）。
- 主按钮：**HERO 大按钮「播放」（有续播进度则从进度续播）或「预约/已预约」**（`A/b.java:2575-2600`；预约需登录：`"登录后才可以添加预约"`）。
- 选集：分页数量可设 **10/20/30/40/50 集每页（默认 20 · 一屏两行）**（`C0407m0.java:541`）；集按钮带观看进度百分比与「第 X / Y 集」文案（`L0.java:1360, 1540-1542`）；支持**「已看完 / 未看完」筛选**（`L0.java:5379`）。
- 「简介」以通用对话框 `i2` 弹出（`p011d1/Y0.java:87` `new i2(mainActivity4, "简介")`）。
- 详情页播放器内嵌试看/预告，画面上叠「点击进入正片」入口（`L0.java:1916-1929` `M2()`：`textView2.setText("点击进入正片")`）。
- 未上线剧支持「预约」并触发上线提醒（预约写接口 + `"登录后才可以添加预约"`）。

### 1.6 播放器形态 `[一手]`

- ExoPlayer `PlayerView`；**画面缩放三模式**（`sources/p011d1/L0.java:9344-9355` `z0()`：RESIZE_MODE_FIT=0 / ZOOM=4 / FILL=3），设置项「全局画面模式」：**完整画面（保留比例与全部内容）/ 等比铺满（会裁掉部分画面与字幕）/ 拉伸铺满**（`C0407m0.java:650`）。竖屏剧默认按比例适配（FIT，即两侧留黑），由用户手动切换。
- 底部 HUD 控制条（`j()`="controls" `MainActivity.java:2028-2033`、`o()`="hud"）：显示 **清晰度 Xp / 倍速 X / 弹幕 开关 / 定时 X**（`L0.java:2796-2825`）；HUD 状态项可选：剧名/剧集/网速/时间（`AbstractC0410n0.java:55`）。
- **选集面板**从播放器呼出（按键映射 `sources/F0/EnumC0156h2.java:13-15`：`"选集 · 打开底部选集面板，挑一集接着看"`），分页数量同 1.5。
- 快进退：**每次 10 秒，连按 5 次后每次 30 秒**（`EnumC0156h2.java:21-24`）；上一集/下一集直接切换。
- 支持**弹幕**（显示开关 + 移动速度设置 `C0407m0.java:923`；换集提示「上一集 X 条弹幕」`L0.java:2583`）、**定时停止**（`L0.java:603` `"定时停止已生效 · 观看位置已保存 · 按播放可继续"`）、倍速（全局默认倍速设置 + 「2 倍速播放中」提示 `L0.java:4968`）、断网续播提示（`L0.java:2746`）、失败自动重试 3 次后提示手动换清晰度（`L0.java:2742`）。
- 播放器按键可自定义（`EnumC0156h2` 枚举即按键→动作映射表，含「无」）。

### 1.7 搜索 / 登录形态 `[一手]`

- 搜索页（catalog a3=1）：**300×52dp 搜索输入框**（hint「输入剧名或关键词 · 可按「语音」说话或遥控器选字」，80 字上限）+ 「搜索」按钮 + **「手机输入」按钮**（手机扫码/配对代输入）+ 搜索历史（**最多 20 条**，可清空）+ 空态文案「遥控器用方向键选字，也可外接键盘」。
  - 证据：`L0.java:3014-3060`（`Z1()`）、`L0.java:3177`、`L0.java:4273`。
- **语音搜索**：系统 `android.speech` RecognizerIntent，结果去掉前缀词、限 80 字（`MainActivity.java:2069-2160`，`"没有听清，请再说一次"`）。
- 搜索源可切换（App 搜索 / 官网搜索，失败自动降级：「App 搜索接口没有数据，已自动改用官网搜索」`core/b.java:2828`、`C0407m0.java:516`「只影响搜索，分类 / 榜单 / 播放不受影响」）。
- 登录（TV 端）：**扫码登录（二维码 60 秒有效自动刷新）/ 手机号登录（短信验证码）/ 导入账号参数** 三方式；文案「登录后，收藏与观看记录会与账号同步；不登录也能正常看，记录只保存在本机」。
  - 证据：`sources/com/hgtv/star/phone/PhoneAccountActivity.java:84, 568-622, 1268-1278`。
- 「手机备份与恢复」：收藏/历史/搜索/稍后看/隐藏剧 导出合并（合并规则：收藏合并、进度取较新、收藏上限 500、历史 200 条——`p011d1/q2.java:66`）。

### 1.8 色彩与风格基调 `[一手]`

- **不是**抖音官方的纯「黑底白字+红橙点缀」，而是**20 套可选主题（11 深色 + 9 浅色）**，默认「深海蓝 · 冷调深色」。
  - 证据：`sources/p008c1/o.java:26-46`（枚举：深海蓝/石墨灰/午夜紫/松林绿/暖棕夜/酒红夜/暗金岩/深海青/钢蓝夜/墨紫夜 + 雾霾蓝/奶油米/薄荷浅/樱粉浅/薰衣浅/天青浅/燕麦灰/浅柠檬/浅珊瑚/浅灰绿，各带 `deep-dark`/`light` 标记）。
- 默认深海蓝主题色值（由枚举常量计算）：
  - 页面底 `#1E2228`、卡片面 `#2A3038`、更深底 `#12151A`、主文字 `#F2F5F8`、次要文字 `#AAB4C0`、**强调色（选中点/★）`#4DA3FF`（蓝）**、次强调 `#5B8DEF`、角标辅助红 `#FF6B6B`。
- 面板用半透明圆角浮层（alpha 240/184 两档，`l2.java:83-95`），配 1px 描边（`l2.java:97-104`）。
- 焦点语言统一：**缩放 1.05 + 200ms + 发光描边 + 跑马灯**（见 1.3）。

### 2.1 首页信息架构 `[一手]`

- **左侧固定侧边栏（200px，可切仅图标 104px）**：品牌 + 主导航 **推荐 / 找剧 / 排行榜 / 新剧 / 历史 / 收藏 / 追更 / 打赏**，底部分组 **我的 / 设置**；追更带红点角标。

### 2.2 卡片形态 `[一手]`

- 首页推荐流上的「热播短剧」横滑小卡：**142px 宽横版图（112px 高 ≈ 1.27:1）+ 标题 13px + meta 11px**，半透明底。
  - 证据：`app.css:208-213`。
- 焦点态：**白色描边光环（box-shadow 0 0 0 3px #fff）+ 轻微放大位移**（卡片 `translateY(-4px) scale(1.035)`，侧边栏项 `scale(1.018)`）。

### 2.3 榜单页形态 `[一手]`

### 2.4 详情页形态 `[一手]`

- 详情是**模态弹窗**（`#detail-modal`）：头部 = 封面图 + 「选集」标题 + meta + **追更 / 收藏**两按钮 + 简介；下方 **演员条**（detail-cast-strip，可展开全部演员弹窗）；再下 **四个 tab：选集 / 系列剧 / 剧评 / 相关推荐**；选集面板带读取进度与重试。

6. 焦点语言趋同：**放大 + 高亮描边/光环**，HGTV 额外加跑马灯与抬升阴影。

## 6. 对 MyBLBL 红果模块重设计最有借鉴价值的 3 点

1. **首页双形态分层（HGTV 验证）**：货架式首页（继续观看/收藏/稍后看 + 四榜单各取前 10 + 分类货架，每行 ≤10 张、行尾「查看全部」）承载找回与追剧，遥控器「推荐」键直达全屏自动连播推荐流；两者共用同一卡片系统。这同时满足「老用户效率」与「新用户刷剧」，是 TV 端被验证过的完整答案（§1.2）。
2. **竖版海报卡 + 名次角标体系（四端验证）**：主卡片定死竖版 2:3~3:4 + CENTER_CROP；角标按「左上=榜单名次/状态（前三名特殊配色）、右上=季/更新、左下=热度、右下=共 N 集」，历史卡加底部进度条；焦点态统一「放大 1.03~1.05 + 高亮描边（可加标题跑马灯）」。一套卡片覆盖首页/搜索/分类/榜单/我的全部场景（§1.3、§2.2、§3.1）。
3. **竖屏剧播放策略 + 手机代输入（TV 刚需）**：播放页提供「完整画面/等比铺满（裁切）/拉伸」三档画面模式，竖屏剧默认保持比例，可选当前画面模糊延伸背景（hongguo-tv 的 portrait-backdrop 是现成方案名）；遥控器文字输入用「三栏搜索」（键盘/联想/结果）+ 全屏数字键盘 + **扫码用手机代输入**兜底，登录走扫码 + 手机号双通道（§1.6、§1.7、§2.5、§2.6、§4.5）。
