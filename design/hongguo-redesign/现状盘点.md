### 1.1 HongguoFragment 主容器（fragment_hongguo.xml）

**布局层次**
```
ConstraintLayout (match/match)
├─ TabLayout tabLayout            高px80 marginTop px25 paddingH px30 scrollable
│    tabIndicator=@drawable/underline 高px10 ?attr/colorAccent 不全宽
│    tabTextAppearance=@style/TopPageTabText (px40 bold)
│    选中字 ?android:textColorPrimary / 背景、ripple 全透明
├─ LinearLayout button_hongguo_search   右上搜索胶囊：bg_search_input 高px60 paddingH px20 marginEnd px30
│    ├─ ImageView 图标 px40 (ic_search, tint textColorSecondary, padding px6)
│    └─ TextView "搜索" px24 textColorSecondary marginStart px8
├─ ViewPager2 viewPager           marginTop px105 (=25+80, 正好贴 tab 下缘) match×0dp
└─ FrameLayout container_hongguo_search  全屏搜索覆盖层, background=?windowBackground, 默认 gone
```

**视觉风格**：顶部一行大号下划线式页签 + 右上搜索胶囊，覆盖层用窗口背景整页盖住六页签。无自绘背景/渐变，全部走主题属性。

**焦点/遥控**
- `enableTouchNavigation`（与 B 站各主页签同款）：OK 键瞬切+滑入动画；UP/左边缘逃侧栏（落侧栏当前主 tab），DOWN 落当前页第一张卡，右边缘进搜索胶囊（`HongguoFragment.kt:117-130`）
- 离屏 ViewPager2 页全部 `FOCUS_BLOCK_DESCENDANTS`，防遥控按键被不可见页几何截走（`HongguoFragment.kt:97-103`）
- BACK：搜索层显示时先收层（焦点回搜索胶囊），否则透传退出链；回调用 `isEnabled=false→转发→true` 防永久失效（`HongguoFragment.kt:57-73`）
- 侧栏切回红果 tab 时焦点回顶部页签（`observeTabSelected`）

**弱点**
- 搜索入口是文字胶囊而非输入框形态，与 B 站主 tab 搜索入口的视觉关系未对齐（引用同一 bg_search_input 但高度 px60 vs 主 App 输入框形态）
- 覆盖层是 `windowBackground` 纯色盖板，无入场过渡/半透明遮罩，搜索打开观感是「整页瞬切」

### 1.2 HongguoFeedPage 推荐页（fragment_hongguo_feed.xml）——推荐/历史/收藏三 tab 共用

**布局层次**
```
LinearLayout (vertical, match/match)
├─ RecyclerView recycler_filters   筛选 chip 行：paddingH px30 paddingV px10, 默认 gone（仅在线 feed 有 selector_rows 后显示）
└─ FrameLayout weight=1
   ├─ RecyclerView recycler_feed   paddingH px20 paddingBottom px20 clipToPadding=false
   │    WrapContentGridLayoutManager 6 列（超宽屏 12 列），GridSpacingItemDecoration 间距 px16
   ├─ TextView text_empty          "暂无内容" px28 @color/grey 居中, gone
   └─ ProgressBar progress_loading px60 居中, gone
```

**视觉风格**：内容即 6 列 4:5 竖版卡片瀑布（统一 `HongguoDramaAdapter`，见 1.11），无页头/横排位/任何装饰；历史/收藏卡带封面底部进度条（卡片工厂自带）。筛选 chip 是 `button_common` 主题底胶囊（px56 高 px24 字）。

**焦点/遥控**
- `TvListFocusController` + `GridTvFocusStrategy(6列)` 统一焦点链：触底预加载（焦点距尾 4 项）、离开页面捕获锚点、返回恢复锚点（`onPause/onResume`）
- 卡片顶行 UP 回红果顶部 tab（`bindTopEdgeUp → host.focusTopTab()`）
- `focusFirstCard()`：侧栏 RIGHT / tab DOWN 的统一入口，落第 0 张卡
- 筛选 chip 点击不展开面板，弹通用 `ChoiceDialog` 单选；选中后 `notifyDataSetChanged`

**弱点**
- 筛选选中态无视觉反馈：`FilterChipAdapter` 设置 `text.isSelected = selectedId != null`（`HongguoFeedPage.kt:241`），但 chip 背景 `button_common` 的 selector **没有 state_selected 分支**（`button_common.xml` 只有 pressed/focused/default），选中后只有文字从「类型」变「类型·值」，底色不变
- 筛选交互是「chip 弹窗」而非 TV 惯用的左侧筛选栏/下拉面板，一维度一点一弹，多维度筛选路径长
- 空态只有一行灰字 + 居中 ProgressBar，无插画/重试按钮
- 推荐页与历史/收藏共用一布局但筛选行仅推荐有，历史/收藏页顶部留白逻辑不同（paddingV px10 的 gone 行）
- 历史/收藏是本地秒显 + 云端合并两段刷新，进度条只在第二段出现，视觉上闪一下

```
   └─ ProgressBar progress_rank   px50, gone
```

**视觉风格**：子板切换用 **原生 RadioButton**（系统圆点+文字，未做 TV 化样式），与主容器 TabLayout、分类页 TabLayout、搜索 chip 三种页签形态并存。榜单卡与推荐卡同款，排名走封面左上「第 N 名」橙底角标（金银铜配色由 `coverMetaOverlay.typeBadge` 承担，见 1.11 代码注释与 `HongguoRankPage.kt` 类注释）。

- 网格部分与 feed 同款 `TvListFocusController`；卡片顶行 UP 回 tab；`focusFirstCard` 落第 0 卡

- 四板切换形态（原生 RadioButton）是全模块最突兀的控件：无背景、无选中底色、系统圆点样式与整体 TV 风格脱节
- 「四板榜单」标题叫榜单，实际四板是平铺 RadioButton 而非榜单页常见的「左板右榜」或顶部分段控件；与红果官方榜单页信息结构差异大
- 榜单排名信息只在封面角标「第 N 名」，网格铺开后缺少排名序号列/前三强化的榜单叙事（官方榜单卡有类型行副标题，本项目 subtitle 已对齐 tags）

- 结果态无「换个词试试」入口（strings 已备 `hongguo_search_retry` 未使用）

## 2. 横向总结

### 2.1 颜色使用清单

**主题属性引用（随用户主题变化）**
- `?attr/colorAccent`：主容器/分类页 tab 指示条、搜索框聚焦描边、我的页头像 tint。实际值随主题：DarkTheme 默认 `#bb86fc`（紫）、ClassicsTheme `#FB7299`（B 站粉）、BlueTheme `#7f97d2`（蓝）（styles.xml:13-25, colors.xml:29-30,139-140）
- `?attr/colorPrimary`：登录页签选中底、选集格按压底
- `?attr/colorControlHighlight`：全模块统一聚焦高亮底
- `?attr/buttonBackgroundColor`：chip/描边钮/页签默认底
- `?android:textColorPrimary/Secondary` + `@color/grey #cccccc`、`@color/textColor #eeeeee`、`@color/white`、exo 白系

**硬编码色值（不随主题，共 10+ 处）**
| 色值 | 位置 | 用途 |
|---|---|---|
| `#FF5C1F` / `0xFFFF5C1F` | hongguo_btn_play.xml、HongguoDramaAdapter.kt:104、HongguoSearchPage.kt HotBoardAdapter | 红果橙：主按钮底、排名角标、热搜前三 |
| `#FF4D26` / `0xFF3FA45B` / `0xFF6A5AE0` | HongguoDramaAdapter.kt:106-110 | 爆剧/新剧/其他状态角标 |
| `#FFB28F` | activity_hongguo_player.xml | 播放器清晰度文字 |
| `#E6FB7299` | activity_hongguo_player.xml（TimeBar played_color） | 进度条已播（B 站粉 90% 透明变体） |
| `#40FFFFFF` | 同上 | 进度条未播 |
| `#F2FFFFFF` / `#14FFFFFF` | bg_hongguo_episode.xml、bg_hongguo_page_chip.xml、bg_cctv_vod_episode_cell.xml | 选中白底 / 默认半透明白底 |
| `#CC000000→#00000000` | hongguo_cover_bottom_shade.xml | 播放器顶栏渐变 |
| `0xDD000000` / `Color.WHITE` | HongguoDetailDialog.kt:275,299 | 选集/分页选中文字 |
| `0x66000000` | HongguoDramaAdapter.kt | 季数/空标签角标底 |

**结论**：红果橙 #FF5C1F 与主题 colorAccent（紫/粉/蓝）双色彩体系并存——tab 指示条、聚焦色随主题漂移，而红果主按钮/角标/热搜前三固定橙，主题切到 Classics（粉）时同屏出现橙+粉两种强调色。

### 2.2 字号 / 间距体系

- **字号档**：px20（tip）/px22（uid、清晰度）/px24（正文主力：chip、meta、按钮次级）/px26（按钮主、radio、选集格、热搜标题）/px28（uid 输入框、联想词、热搜 rank）/px30（区块标题、空态、搜索输入）/px32（昵称）/px35-36（时间、详情标题）/px40（主 tab、播放器标题）/px50（时钟）——约 10 档，px24/26/28 三档密集且区分度低
- **间距**：网格间距 px16（全模块统一）、页面水平 padding px20/px30、弹窗 padding px30-40、区块 marginTop px24——大体有规律
- **控件高度五档并存**：chip px56、分页 chip px60、选集格 px64、登录页签/按钮 px64-70、热搜行 px68、联想行 px72、输入行 px76、详情按钮 px76、tab 行 px80——相近语义的行块高度未归一
- **空态/加载**：empty 字号 px28（feed）/px30（rank/search），进度条 px60（feed/login）/px50（rank/search）/px70（播放器）

### 2.3 Tab 名称与顺序

- 红果页内六 tab（`HongguoFragment.PAGE_TITLES` + strings.xml:87-92）：**推荐 → 历史 → 收藏 → 榜单 → 分类 → 我的**
- 分类页子 tab：全部 → 漫剧 → AI剧（代码硬编码）；榜单页四板：热播榜 → 真人榜 → 漫剧榜 → AI剧榜（strings.xml:128-131）
- 红果在主侧栏固定序第 7 位（TAB_INDEX=6，0推荐/1分类/2动态/3直播/4CCTV直播/5CCTV影视/6红果/7我的/8搜索）

### 2.4 跨模块借用资源（重设计时的耦合点）

- `bg_cctv_vod_episode_cell`（CCTV 选集格）→ 热搜榜行背景
- `bg_owner_dialog_outline_button`（B 站 UP 主弹窗）→ 登录弹窗刷新/发送验证码钮
- `button_common` / `bg_search_input` / `underline` / `dialog_background` / `default_video` / `focus_background` / `cell_background`（B 站播放器）→ 全模块散用
- 播放器组件整体复用 B 站：`PlayerControlButton`、`DefaultTimeBar`、`ic_progress_head`、exo 白系色
- 红果自有 drawable 6 个中，`bg_hongguo_episode` 与 `bg_hongguo_page_chip` 内容近乎重复（仅文件注释不同），且二者与 `bg_cctv_vod_episode_cell` 结构同构（三胞胎 selector）

### 2.5 最突出的设计问题（重设计优先级建议）

1. **页签/切换控件形态四分天下**：主容器下划线 TabLayout（px80/px10）、分类页下划线 TabLayout（px70/px8）、榜单页原生 RadioButton、登录弹窗自绘 TextView 页签——四种「同语义」控件四种长相，且参数互不统一
2. **双色彩体系冲突**：红果橙 #FF5C1F（硬编码 10+ 处）vs 主题 colorAccent（随主题紫/粉/蓝），主题切换后强调色同屏打架；色值未资源化导致重设计无单一改色点
3. **弹窗/列表承载过重**：稍后再看、我的预约是纯文字 ChoiceDialog；筛选是 chip 弹 ChoiceDialog；登录/详情是固定尺寸 overlay 弹窗——大量核心内容路径都压进弹窗，TV 遥测路径长、无封面视觉
4. （次级）行高五档/字号十档未归一；bg_hongguo_episode/page_chip 重复资源；搜索态无空结果行动入口；播放器 UP/DOWN 切集无确认
