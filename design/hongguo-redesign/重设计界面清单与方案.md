# 红果短剧 TV UI 重设计——界面清单与设计方案（v1 待确认）

> 2026-11-11。依据：同目录《现状盘点.md》（我方 9 屏逐屏盘点）+《参考形态盘点.md》（HGTV / hongguo-tv / open-player / tsukiyo 四端调研）。
> 本文档只回答一件事：**需要设计哪些界面、每屏往哪个方向改、先做哪批**。逐屏高保真设计稿待本清单确认后产出。

## 一、先定调：三条全模块统一的设计基调

所有界面重设计都从这三条出发，避免再长出「四分天下」的控件：

1. **一套卡片语言**：全模块主卡 = B 站统一竖版卡（POSTER_4_5，已迁移，保留）。角标四槽位定死——左上＝名次/状态（前三名金银铜特殊样式）、右上＝季/更新、左下＝热度、右下＝共 N 集，底部进度条（历史/收藏）。一套卡覆盖推荐/搜索/榜单/分类/我的全部场景。
2. **一套切换控件**：所有「同语义页签」统一为一种 TV 分段控件（选中＝主题强调色实底/白字，聚焦＝高亮描边），替代现在的四种形态（主 tab 下划线 / 分类子 tab / 榜单 RadioButton / 登录自绘页签）。主容器六 tab 可保留下划线式（与全 App 顶层一致），但参数归一，模块内二级切换一律用新分段控件。
3. **一套色彩与规格**：新增 `colors_hongguo.xml` 把 10+ 处硬编码色收编为资源——强调位全部改主题引用（?attr/colorAccent/colorPrimary），仅榜单语义色保留独立资源：前三名金 `#FFC53D` / 银 `#C0C7D1` / 铜 `#E09B62`、爆剧红橙 `#FF4D26`、新剧绿 `#3FA45B`、标签紫 `#6A5AE0`。行块高度归一为三档：chip px56 / 行 px68 / 主按钮 px70；字号收敛到 6 档（20/24/26/30/36/40）。焦点语言延续全 App（放大 + 高亮描边 + 标题跑马灯）。

> **基调定案①（强调色，已拍板）**：红果模块**全面跟随全局主题**——删掉 10+ 处硬编码红果橙，主按钮/名次角标/热搜前三/清晰度等强调位一律改 `?attr/colorAccent`/`colorPrimary` 主题引用；仅榜单语义色（前三名金银铜徽章、爆剧红橙、新剧绿）作为独立语义色资源保留。设计稿示例色以默认深色主题（紫 #bb86fc）绘制，稿上全部标注为主题引用。

## 二、需要设计的界面清单（9 屏 + 3 公用件）

### A 级——整页重设计（现状最粗糙，第一波出稿）

**1. 我的页（HongguoMinePage）**
现状：居中单列按钮堆叠，稍后再看/预约是纯文字弹窗，信息密度极低。
方向：
- 重排为「左账号卡 + 右功能区」两栏：左侧账号卡（头像占位、昵称、红果号、云同步状态徽标、登录/退出主按钮）；右侧功能卡区（稍后再看 / 我的预约 / 本机收藏 / 观看历史 四张横卡，各带数量角标 + 最近一条封面缩略）。
- 「稍后再看」「我的预约」从纯文字 ChoiceDialog 升级为**封面卡片横滑货架**（复用统一竖版卡，稍后再看卡带「看到 x/y 集」进度），点卡片进详情弹窗。
- 「清除本机红果数据」降权收进账号卡底部小字按钮，与普通操作分离；未登录时隐藏不可用项。

**2. 榜单页（HongguoRankPage）**
现状：四板切换是原生 RadioButton（系统圆点），与全模块风格最脱节。
方向：
- 四板换统一分段控件（热播/真人/漫剧/AI剧，选中＝主题强调色实底）。
- 榜单本体**只保留海报网格（已拍板）**：统一竖版卡 + 第 N 名角标 + **前三名金银铜徽章强化**（金 #FFC53D / 银 #C0C7D1 / 铜 #E09B62，独立语义色资源），第 4 名起角标用主题强调色。
- 顶部加榜单说明行（「基于热度综合排序 · 每日更新」灰字一行，文案可后定）。

**3. 登录弹窗（HongguoLoginDialog）**
现状：三通道页签结构可用，但三种按钮背景同屏、主次动作不分。
方向：
- 按钮体系统一：主行动（登录/导入/我已发送）＝橙实底；次行动（刷新二维码/发送验证码）＝描边钮；发送验证码属于短信通道关键动作，升为描边高亮并在倒计时中变灰。
- 三页签换统一分段控件；扫码区白底块加圆角+内衬卡片；底部加一行免责/隐私灰字（文案后定）。
- MFA 指引从裸文字行升级为浅底提示卡（图标 + 指引 + 按钮）。

### B 级——信息架构或布局动刀（第二波出稿）

**4. 主容器 + 推荐页（HongguoFragment + HongguoFeedPage）**
现状：六 tab 平铺网格，无页头；筛选 chip 无选中态、点选弹 ChoiceDialog。
方向：
- **基调定案②（信息架构，已拍板）**：设置的「红果短剧」组**新增开关「红果页显示历史/收藏」（默认开启）**：开＝顶层六 tab（推荐/历史/收藏/榜单/分类/我的）；关＝顶层收敛为四 tab（推荐/榜单/分类/我的），历史与收藏并入「我的」页入口卡（我的页 A 级重设计已按此预留四张入口卡，两态天然兼容）。实现落点：SettingsFragment 红果组 + HongguoFragment.PAGE_TITLES 动态构建 + MeFragment event.index 联动点。
- 推荐页顶部加**「继续观看」横滑货架**（本地历史前 N 部，带进度条，一行卡片），下方才是筛选行 + 网格——老用户一进红果就能续剧。
- 筛选行升级：chip 带选中态（橙底/橙描边），多维度筛选改为「chip 行 + 下方展开面板」一次到位（替代一维度一弹窗）。

**5. 搜索页（HongguoSearchPage，三态）**
现状：结构完整，但发现态是「灰字标题分区」，观感偏设置页。
方向：
- 发现态区块卡片化：历史/猜你想搜词 chip 归一为一种 chip；热搜榜两列改**带排名徽章的榜卡**（前三名金银铜数字徽章 + 火焰图标 + tip 位次变化，字段已有），区块加浅底圆角容器。
- 空结果态加行动入口：「换个词试试」＋热搜前三词 chips（strings 已备 `hongguo_search_retry` 未使用）。
- 结果态/联想态沿用统一竖版卡，只做规格归一。

**6. 详情弹窗（HongguoDetailDialog）**
现状：结构对齐官方，但选集区弱、评分无强调。
方向：
- 评分橙色强调（★ 8.6 橙字），标签行改小 chip 形态。
- 选集格加进度语义：正在看＝橙底，看过的集＝右下小圆点/勾，未看＝现样式；分页 chip 与选集格高度归一。
- 短剧（≤1 页）时隐藏分页行；集数超多时选集区右下加「跳转到第 N 集」入口（可后置）。

### C 级——规格对齐与微调（第三波出稿，量小）

**7. 分类页（HongguoCategoryPage）**：子 tab（全部/漫剧/AI剧）参数与主 tab 归一并接焦点接管；若拍板②通过，分类页子 tab 与筛选行合并，页面只剩一层。
**8. 播放器（HongguoPlayerActivity）**：清晰度/进度条颜色入 `colors_hongguo.xml`；时间格式补小时位；**DOWN 呼出半屏选集面板**（替代现在 UP/DOWN 直接切集无反馈，参考 HGTV/tsukiyo）；竖屏剧「完整画面/等比铺满/拉伸」三档 + 模糊延伸背景（对应 P3 待办，设计稿先出形态）。
**9. 主容器 tab 行**：搜索入口与 B 站主 tab 搜索框形态对齐；tab 参数归一；按定案②新增「红果页显示历史/收藏」开关的两种顶层形态（六 tab / 四 tab）。

### 公用件（随第一波一起定稿）

- **统一剧卡角标体系**：色板资源化 + 前三名金银铜徽章样式（全模块生效）。
- **chip / 行 / 按钮三档规格**：一种 chip（px56，含选中态）、一种行（px68）、主/次按钮两态。
- **空态/加载态**：统一空态（图标 + 一句话 + 重试按钮）与加载样式，替代灰字 + 裸 ProgressBar。

## 四、决策记录（2026-11-11 已拍板）

1. **强调色**：跟随全局主题，删硬编码橙，强调位全部主题引用；榜单前三名金银铜为独立语义色。
2. **信息架构**：设置「红果短剧」组新增开关「红果页显示历史/收藏」，默认开＝六 tab；关＝四 tab，历史/收藏并入我的页。
3. **榜单形态**：只保留海报网格，四板换统一分段控件 + 前三名金银铜徽章强化。

三项已定，第一波 4 张设计稿（我的页/榜单页/登录弹窗/公用件）按此开工。
