# MyTVB

📺 一个专为 Android TV 设计的第三方 Bilibili 客户端，同时适配手机、平板与车机触屏，像素级对齐 BLBL。

## ✨ 主要功能

- 🎬 **视频播放** - UGC 视频、番剧、电影、电视剧、纪录片；支持 8K / 4K 超高清、HDR 真彩、杜比视界等画质档位，档位不可用时自动降档不中断播放
- 💬 **弹幕引擎** - 轻量化引擎，支持人物区域智能防挡；字号、透明度、速度、行距、显示区域全可调，支持合并重复弹幕、按等级过滤
- 📝 **评论面板** - 查看评论与楼中楼回复，评论配图可放大，长评论展开收起，样式对齐官方
- 📡 **直播 & 电视直播** - B 站直播弹幕即时显示；电视直播（央视频道等）遥控器上下切台，频道列表与画质菜单可选
- ✈️ **空降助手** - 自动跳过恰饭 / 开场 / 片尾片段，进度条显示片段标记
- 🎮 **互动视频 / 上下滑切换视频** - 互动分支选择；上下滑动切换推荐视频
- 👶 **青少年模式** - 观看时长与休息限制、公益广告
- 🖱️ **长按快捷菜单** - 视频卡片长按唤起：加入稍后观看、收藏、视频详情、UP 主主页、不感兴趣
- 📲 **完整账号体验** - TV 端扫码登录；大会员、头像框、等级徽章全应用显示；历史 / 收藏 / 稍后再看，关注 / 粉丝列表
- 🔍 **搜索** - 视频与用户搜索，用户卡片可直接关注
- 🌏 **多语言** - 简体中文 / 繁體中文（台灣）/ English，跟随系统自动匹配，也可手动切换
- 🖥️ **界面适配** - 界面缩放 80%~150%、界面文字大小、视频卡片大小均可调；带鱼屏、车机屏等特殊分辨率首次安装自动适配
- 🎚️ **播放设置** - 默认画质 / 音质 / 倍速 / 编码，无缝切换清晰度，音量均衡，字幕「关 / 开 / 自动」三态

## 💡 小技巧

- ⏩ **播放倍速** - 播放中长按 OK 临时 2 倍速（在当前倍速上再翻倍，松手还原）；「设置 → 播放设置」可自定义默认倍速（最高 3.0x），也可开启"音乐区视频默认 1 倍速"
- ⏪ **快进快退** - 长按左右键约 10 秒走完全片；轻按一下快退 / 快进 10 秒，可连按累积；长按拖动时画面定格不跳动，底部显示瞬时进度条与画面预览小窗
- 🔄 **回到顶部 / 刷新** - 列表页按菜单键，或重新选中当前标签页，即可回到顶部并刷新当前分区
- 🔙 **逐级返回** - 返回键按「内容 → 标签栏 → 侧边栏」逐级回退；播放页、直播页呼出控制栏后左上角有返回按钮，触屏 / 车机不用遥控器也能返回
- ↔️ **边缘切换标签** - 焦点在列表最左 / 最右边缘时继续按方向键，直接切换到相邻标签页
- 🎛️ **自定义控制区按键** - 「设置 → 播放界面」可把底部常驻进度条、上一个 / 下一个视频按钮、倍速按键、常驻倍率加到控制区；「设置 → 弹幕设置」可加弹幕开关按键
- 🔊 **音量均衡 / 无缝清晰度** - 不同视频音量自动拉齐（四档，默认中档）、切换清晰度无缝衔接（默认开启），播放中即时生效
- 📺 **电视直播操作** - 上下左右键切台，确定键呼出控制栏，菜单键打开频道列表
- 🕘 **历史自动刷新** - 历史页每次进入都拉取最新观看记录，进度不会再停留在旧数据

## 🛠️ 技术栈

- **Kotlin 2.1.0** · MVVM + Koin 依赖注入
- **Coroutines + Flow + LiveData** 异步
- **Retrofit + OkHttp + Gson** 网络层
- **Media3 (ExoPlayer)** 视频播放（电视直播走 WebView，可选腾讯 X5 内核）
- **弹幕引擎**（Protobuf 协议解析）
- **DataStore Preferences** 数据存储
- **三语国际化**（简体中文 / 繁體中文 / English）
- **AndroidX** UI 组件
- **minSdk 23 (Android 6.0)** / **targetSdk 35 (Android 15)**
