# MyTVB

📺 一个专为 Android TV 设计的第三方 Bilibili 客户端，同时适配手机、平板与车机触屏，像素级对齐 BLBL。

## ✨ 主要功能

- 🎬 **视频播放** - UGC / 番剧 / 电影 / 电视剧 / 纪录片；8K / 4K / HDR / 杜比视界
- 💬 **弹幕引擎** - 智能防挡；字号、透明度、速度、行距、区域可调
- 📝 **评论面板** - 评论、楼中楼回复与评论配图
- 📡 **直播 & 电视直播** - 直播弹幕即时显示；央视频道遥控器上下切台
- ✈️ **空降助手** - 自动跳过恰饭 / 开场 / 片尾
- 🎮 **互动视频 / 抖音模式** - 互动分支选择；上下滑动切换推荐
- 👶 **青少年模式** - 观看时长限制、休息提醒、公益广告
- 🖱️ **长按快捷菜单** - 稍后观看、收藏、视频详情、UP 主主页、不感兴趣
- 📲 **扫码登录** - TV 端扫码；大会员 / 头像框 / 等级徽章全应用显示
- 📚 **我的** - 历史、收藏、稍后再看、关注 / 粉丝列表
- 🔍 **搜索** - 视频、用户搜索，可直接关注
- 🌏 **多语言** - 简体中文 / 繁體中文 / English
- 🖥️ **界面缩放** - 缩放、文字、卡片大小可调；特殊分辨率自动适配
- 🎚️ **播放设置** - 画质 / 音质 / 倍速 / 编码、无缝清晰度、音量均衡、字幕三态

## 💡 小技巧

- ⏩ **播放倍速** - 长按 OK 临时 2 倍速；默认倍速最高 3.0x，音乐区可默认 1x
- ⏪ **快进快退** - 长按左右约 10 秒走完全片；轻按 10 秒可连按；拖动带预览小窗
- 🔄 **回到顶部 / 刷新** - 列表页按菜单键，或重选当前标签
- 🔙 **逐级返回** - 内容 → 标签栏 → 侧边栏；播放页左上角有返回按钮
- ↔️ **边缘切标签** - 焦点在列表最左 / 最右边缘时继续按方向键
- 🎛️ **自定义控制区按键** - 常驻进度条、上 / 下一个、倍速、弹幕开关等可加入（设置 → 播放界面）
- 🔊 **音量均衡 / 无缝清晰度** - 默认开启，播放中即时生效
- 📺 **电视直播操作** - 上下切台、确定键呼出控制栏、菜单键选频道
- 🕘 **历史自动刷新** - 进入历史页即拉取最新记录

## 🛠️ 技术栈

- **Kotlin 2.1.0** · MVVM + Koin 依赖注入
- **Coroutines + Flow + LiveData** 异步
- **Retrofit + OkHttp + Gson** 网络层
- **Media3 (ExoPlayer)** 视频播放（电视直播走 WebView，可选腾讯 X5 内核）
- **弹幕引擎**（Protobuf 协议解析）
- **DataStore Preferences** 数据存储
- **三语国际化**（简体中文 / 繁體中文 / English）
- **AndroidX** UI 组件
- **minSdk 23 (Android 6.0)** / **targetSdk 35 (Android 15)**
